# Product

## Register

product

## Users
Power users, developers, support engineers, and creators who need fast capture, copy, save, and upload workflows on Windows x64 and macOS Apple Silicon with minimal background overhead.

## Product Purpose
ShareX Lite is a lightweight cross-platform rewrite inspired by ShareX's task pipeline. Its first version focuses on screenshot capture, quick after-capture actions, upload workflows, history, tray access, global shortcuts, and GitHub-built installers.

## Brand Personality
Quiet, precise, fast. The interface should feel like a dependable desktop utility: compact, direct, and calm under repeated daily use.

## Anti-references
Do not make it feel like a marketing landing page, a decorative Electron dashboard, or a novelty screenshot toy. Avoid oversized hero sections, heavy gradients, broad rounded cards, and UI that hides the capture workflow behind onboarding copy.

## Design Principles
1. Put the capture workflow first: the first screen should be immediately usable.
2. Keep repeated actions one click away: capture, upload, copy URL, open folder.
3. Preserve ShareX's task-pipeline mental model while reducing configuration noise.
4. Treat platform permissions as first-class states, especially screen recording, clipboard, notifications, and shortcuts.
5. Optimize for small installation size and low idle cost before visual flourish.

## Accessibility & Inclusion
Target WCAG AA contrast for text and controls. Respect reduced motion. Use native keyboard focus states, clear status text, and avoid relying on color alone for task state.
